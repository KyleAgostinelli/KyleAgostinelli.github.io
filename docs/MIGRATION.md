# Migration plan

What happens to every file in the current Vite app. "Rewritten" means the concept survives
but the implementation is new (different language, framework, or both); "ported" means the
logic moves with only mechanical changes; "deleted" means it does not survive the migration
in any form.

## Prerequisite (before any file moves)

The working tree has no `.git` directory — this is not a git repository yet. `git init` and
a baseline commit of the current Vite app must happen before Phase 1 starts, so the rewrite
is a reviewable series of commits rather than one opaque replacement. See
`docs/ARCHITECTURE.md`.

## Net effect

Everything in `src/` today is either deleted outright (the fake API, the bespoke CSS, the
classified-file visual backdrop, the router scaffolding) or rewritten into TypeScript with a
different framework substrate. Only two things are pure ports with no logic change: the
resume PDF and the factual content inside `portfolio.js` (which is restructured into typed,
schema-validated modules, but no fact is altered — see `docs/DECISIONS.md` ADR 2 and the
honesty constraint in the Phase 0 brief).
